## 🏦 Meridian Private Bank Suite

Three repositories that work as a single system: risk, intelligence, and capital deployment for a private bank with a synthetic Asia-Pacific HNW/UHNW client universe.

| Layer | Repository | What it does |
|---|---|---|
| **Risk** | [Meridian-Monte-Carlo](https://github.com/dindaatheone/Meridian-Monte-Carlo) | Three Monte Carlo methods: Latin Hypercube Sampling for venture valuation, scenario-based correlated simulation for macro stress testing, and historical simulation for LP reporting. Calibrated against the Q1 2026 Iran war oil shock |
| **Intelligence** | [Meridian-Business-Intelligence](https://github.com/dindaatheone/Meridian-Business-Intelligence) | PostgreSQL and Python analytics across the client universe. Feeds due diligence in the venture layer |
| **Capital** | [Meridian-Ventures](https://github.com/dindaatheone/Meridian-Ventures) | Hybrid PE fund architecture nested inside private banking integration logic. GP/LP blind pool, real options investment thesis, BI-driven due diligence, Expanded NPV valuation, and co-investment mechanics across five Asia-Pacific corridors |
